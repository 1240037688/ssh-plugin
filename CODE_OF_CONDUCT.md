# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Standards

- Be respectful and constructive
- Accept feedback gracefully
- Focus on what is best for the community and users
- Do not publish others’ private data (credentials, IPs, personal info)

## Enforcement

Report unacceptable behavior via GitHub private contact to the maintainers. Maintainers may remove comments, commits, or contributors that violate this code.
